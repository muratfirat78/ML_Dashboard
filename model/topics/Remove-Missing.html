Data Cleaning: Removing missing values


Before dealing with any machine learning models, it is important to deal with missing data first because most algorithms cannot handle missing values directly. Leaving them untreated can lead to inaccurate analysis and poor model performance. The common techniques to handle missing data are:

The two ways of dealing with missing data is either to remove the row that contains a null value or impute it with something else. We will see a bief overview of these two techniques below:

Remove the entire row

One way of handling missing data is removing the rows that contain a Null value. However, we can only do this if the missing values are completely at random (MCAR) and if percentage of missing data is ≤5%.

Advantages of removing rows:

  1. Easy to implement.
  2. Preserve distribution (If data are MCAR, then distribution of dataset should match with distribution of original dataset).

Disadvantages of removing rows:

  1. It can exclude a large fraction of data.
  2. Excluded observation could be informative.
