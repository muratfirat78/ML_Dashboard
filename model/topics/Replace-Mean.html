Data Cleaning: Replace missing values with mean

Mean / Median Imputation

Mean/Median imputation is one of the simplest techniques used to handle missing data in a dataset. If normal distribution of data is present, replace all missing values in a feature with the mean (average) of the non-missing values for that feature. If data is skewed, replace missing values with the median (the middle value) of the non-missing data.

When to use Mean / Median Imputation?

  1. If data is MCAR means the missing values occur completely at random.
  2. If the percentage of missing data is ≤5%

Advantages of mean/median imputation:

  1. Easy to implement.
  2. It works good if number of missing value is low.

Disadvantages of mean/median imputation:

  1. Data Distribution changes.
  2. Sometimes outliers are created.
  3. Relation between current column with other column changes sometimes (covariance and correlation changes).

Points to Remember → If median / mean imputation is applied, variance will shrink. So, keep an eye on the data so that drastic change does not happen.
