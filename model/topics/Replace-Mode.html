Data Cleaning: Replace missing values with most frequent value

Using Most Frequent Value

In this technique, the missing values are replaced with that most frequent values (mode) that appeared on that specific column.

When to use “Replace with Most Frequent Value” technique?

  1. If data is MCAR means the missing values occur completely at random.
  2. If the percentage of missing data is ≤5%

Advantages of “Replace with Most Frequent Value” Imputation:

  1. Easy to apply.

Disadvantages of “Replace with Most Frequent Value” Imputation:

  1. Data Distribution changes.
